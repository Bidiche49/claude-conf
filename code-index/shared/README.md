# Versioned git hooks (.githooks/)

These hooks auto-maintain `docs/.code-map/` (generated by `tool/code_index.dart`).
Installed by [claude-conf/code-index](https://github.com/Bidiche49/claude-conf).

## One-time setup (per clone)

```bash
git config core.hooksPath .githooks
chmod +x .githooks/*
```

After that, the index regenerates automatically:
- after each `git commit`
- after each `git checkout <branch>` (branch switch only, not single-file checkout)
- after each `git pull` / `git merge`

## Manual regeneration

```bash
dart run tool/code_index.dart           # full regen
dart run tool/code_index.dart --quiet   # silent
```

## Disabling temporarily

```bash
git config --unset core.hooksPath
```

## Why these are versioned (not in `.git/hooks/`)

- Single source of truth in the repo
- New devs activate via the one-time setup above
- Updates ship via PR like any other code

## Troubleshooting

- **Hook not running**: check `git config core.hooksPath` returns `.githooks`
- **Permission denied**: re-run `chmod +x .githooks/*`
- **Slow commit**: `dart run tool/code_index.dart --quiet` should take 1-2s after the AOT bootstrap. The first run after editing `tool/code_index.dart` recompiles the binary (~5s).

## Updating

These files are managed by `claude-conf/code-index`. To pull updates:

```bash
bash ~/.claude/code-index/setup-project.sh
```

The setup script is idempotent — it overwrites the hooks but preserves your `tool/code_index.dart` and `docs/.code-map/` artifacts.
